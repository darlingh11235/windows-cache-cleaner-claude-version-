# Windows 缓存清理工具

一个**看得懂、自己做主**的 Windows 缓存清理工具。每一项缓存都写明：

- **为什么会产生**：是谁、在什么情况下写入的
- **它有什么用**：保留它有什么好处
- **清理后会怎样**：删掉之后会有什么副作用
- **建议**：什么情况下适合清理，什么情况下最好保留

工具**默认不勾选任何项目**，扫描只读取、不修改文件，所有清理都由你自己决定。

只用 Windows 自带的 PowerShell 和 WPF，不需要安装任何第三方软件，支持 Windows 10 / 11。

## 使用方法

1. 双击 `启动缓存清理工具.bat`，程序打开后会自动扫描一次（只读取，不删除）。
2. 点击左侧任意卡片，在右侧查看这项缓存的产生原因、用途、清理影响和建议。
3. 勾选你决定清理的项目。顶部会实时显示“已勾选”的总大小；也可以点“勾选所有低风险项”快速选择。
4. 点击“清理已勾选项目…”，确认框会再次列出所选项目、大小以及中/高风险项目的影响，确认后才会删除。
5. 清理完成后会显示释放的空间，并自动重新扫描已清理的项目。

> 想清理标有「需管理员」的项目，可点击程序顶部提示条中的“以管理员身份重新启动”，或右键批处理文件选择“以管理员身份运行”。

## 界面

- 顶部渐变横幅：显示扫描到的缓存总量、已勾选数量与大小、当前权限
- 左侧卡片列表：图标、名称、风险标签（绿 / 橙 / 红）、一句话说明、大小和文件数；大于 100 MB 的项目会以红色数字提示
- 右侧详情面板：产生原因 / 用途 / 清理影响 / 建议 / 所在位置，并会提示“相关程序正在运行”或“需要管理员权限”；可一键在资源管理器中打开所在文件夹
- 底部操作栏：进度条、状态信息和操作按钮

## 缓存项目一览

| 项目 | 风险 | 产生原因 | 用途 | 清理后的影响 |
| --- | --- | --- | --- | --- |
| 当前用户临时文件 | 低 | 软件安装解压、运行时中间文件、更新残留 | 仅在程序运行时临时使用 | 通常无影响；正在使用的文件自动跳过 |
| Windows 系统临时文件 | 低（需管理员） | 系统服务、Windows 更新、管理员安装程序 | 系统级任务的临时工作空间 | 通常无影响；被占用文件跳过 |
| 缩略图与图标缓存 | 低 | 资源管理器生成的图片/视频预览和图标 | 加快文件夹预览显示 | 自动重建，首次浏览时预览稍慢 |
| Windows 错误报告 | 低 | 程序崩溃/无响应时收集的报告 | 向微软或开发者反馈问题 | 无法再查看旧报告，不影响运行 |
| 传递优化缓存 | 低（需管理员） | Windows 更新“传递优化”下载的内容 | 分享给其他电脑、减少重复下载 | 不卸载更新，需要时会重新下载 |
| 系统网页组件缓存 | 低 | IE 内核及调用它的软件缓存的网页资源 | 加快网页内容加载 | 下次加载稍慢，不影响登录状态 |
| 程序崩溃转储 | 低 | 程序崩溃时保存的内存转储 (.dmp) | 开发者分析崩溃原因 | 无法分析旧崩溃，不影响运行 |
| Edge / Chrome / Firefox 浏览器缓存 | 低 | 浏览网页时缓存的图片、脚本、视频片段、GPU 缓存 | 再次访问网站更快、更省流量 | 不删书签/密码/历史/Cookie，首次打开网站稍慢 |
| DirectX 着色器缓存 | 中 | 游戏/图形程序编译着色器的结果 | 避免游戏中途因编译着色器卡顿 | 自动重建，游戏首次运行可能短暂卡顿 |
| 显卡驱动着色器缓存 | 中 | NVIDIA / AMD / Intel 驱动的 DX、OpenGL、Vulkan 缓存 | 同上，让 3D 程序更流畅 | 自动重建，游戏首次运行可能更卡 |
| Windows 更新下载文件 | 中（需管理员） | Windows 更新下载的更新包 | 为尚未完成的更新提供安装文件 | 不卸载更新；若有待安装更新需重新下载 |
| 系统蓝屏转储 | 中（需管理员） | 蓝屏时写入的 MEMORY.DMP 和小型转储 | 分析蓝屏原因 | 无法分析旧蓝屏，不影响运行 |
| 最近使用的文件记录 | 中 | 打开文件时创建的快捷方式 (.lnk) | “快速访问”显示最近文件 | 列表清空（隐私），不删除实际文件 |
| 预读取数据 (Prefetch) | 高（需管理员） | Windows 记录程序启动时读取的文件 | 加快开机和程序启动 | 开机与常用程序会变慢一段时间，几乎不释放空间，**一般不建议** |

风险等级说明：

- **低风险**：可放心清理，删除后会自动重新生成，几乎没有副作用。
- **中风险**：可以清理，但会带来短暂的副作用（如游戏卡顿、需重新下载、丢失诊断信息或使用记录），请按需选择。
- **高风险**：清理收益很小且有明显副作用，一般不建议清理。

## 安全设计

- **只读扫描**：启动时和点击“重新扫描”时只统计文件，不做任何修改。
- **默认不勾选**：所有项目都需要你手动勾选。
- **二次确认**：清理前列出所选项目和大小，中/高风险项目会附上影响说明，默认按钮为“否”。
- **只删扫描到的文件**：清理时只处理扫描清单中的文件，并再次校验文件确实位于对应缓存目录内。
- **不跟随链接**：跳过符号链接、目录联接等重解析点，避免误删其他位置的文件。
- **不强制删除**：正在使用或无权限的文件直接跳过，不会结束进程或修改权限。
- **只清理空目录**：清理后仅删除已经变空的子目录，缓存根目录本身保留。
- **程序运行提示**：检测到浏览器等相关程序正在运行时会提示先关闭。

注意：删除的文件**不会进入回收站**。
